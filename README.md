# Портфолио методиста и педагогического дизайнера

Лендинг-портфолио специалиста, который работает на стыке нейросетей, обучения и педагогического дизайна.

## Технологии

- React 19
- Next.js 16
- Vinext / Vite
- TypeScript
- CSS

## Запуск локально

Потребуются Node.js 22.13 или новее и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска откройте адрес, который покажет терминал. Обычно это `http://localhost:3000`.

## Проверка и сборка

```bash
pnpm lint
pnpm build
pnpm start
```

## Структура

```text
app/
  globals.css    # общие стили и адаптив
  layout.tsx     # корневая разметка и метаданные
  page.tsx       # главная страница
public/
  favicon.svg    # иконка сайта
  og.png         # изображение для соцсетей
```

В Next.js папка `app/` содержит исходный код приложения и выполняет ту же роль, что `src/` в других проектах.

## Публикация на GitHub

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы и папки из этого проекта.
3. Не загружайте `node_modules`, `dist`, `.next` и другие папки, перечисленные в `.gitignore`.

Коммиты и токены для публикации в репозитории не требуются.
